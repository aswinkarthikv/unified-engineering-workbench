Why JTAG is a Debug Interface

A JTAG probe is an IEEE 1149.1 Test Access Port master. It provides dedicated state-machine clocks and instruction registers to read CPU registers, set hardware breakpoints, and program flash. It does not execute user firmware or stream general-purpose application compute.

Complete Analytical Derivation (Sample: $x=1, y=2$)

$$\text{Hidden State: } z = wx + b = (0.5)(1) + 0 = 0.5 \quad \implies \quad h = \tanh(0.5) \approx 0.462117$$
$$\text{Prediction: } \hat{y} = vh + c = (1)(0.462117) + 0 = 0.462117 \quad \implies \quad e = \hat{y} - y = -1.537883$$
$$\text{Loss: } J = \frac{1}{2}(\hat{y} - y)^2 = \frac{1}{2}(-1.537883)^2 \approx 1.182542$$
$$\frac{\partial J}{\partial c} = -1.537883, \quad \frac{\partial J}{\partial v} = -0.710682, \quad \frac{\partial J}{\partial w} = -1.209464, \quad \frac{\partial J}{\partial b} = -1.209464$$

Gradient Direction Explanation

Because the initial prediction $\hat{y} \approx 0.462$ is less than the target $y = 2$, the residual error $(\hat{y} - y)$ is negative. Every parameter derivative is therefore negative.

Gradient descent steps in the negative gradient direction ($-\eta \frac{\partial J}{\partial \theta}$), thereby increasing the weights and biases to push the prediction up towards 2.0 and drive loss to zero.
